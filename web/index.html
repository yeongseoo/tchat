기능

필요한 것만 담았습니다.

💬

방 만들기 · 입장

새 방을 만들거나 목록에서 골라 들어가세요. 몇 명 있는지도 보여요.

👥

접속자 보기

누가 들어오고 나갔는지, 지금 방에 누가 있는지 바로 보입니다.

🏷️

별명

가입 없이 별명만 정하면 끝. 대화 중에도 /nick으로 바꿀 수 있어요.

🫥

저장 안 함

서버는 메시지를 전달만 하고 버립니다. 마지막 사람이 나가면 방도 사라져요.

💻

윈도우 · 맥 · 리눅스

모든 터미널에서 똑같이 동작합니다. 따로 깔 프로그램이 없어요.

⚡

가볍고 빠름

실행파일 하나, 10MB도 안 됩니다. 설치도 삭제도 몇 초면 끝납니다.

자주 묻는 질문

처음 접속할 때 오래 걸려요.

무료 서버라서 한동안 아무도 없으면 잠들어요. 깨어나는 데 30초~1분 정도 걸리니 잠시만 기다려주세요. 한 번 깨어나면 빠릅니다.

대화가 정말 저장되지 않나요?

네. 서버는 메시지를 같은 방 사람들에게 전달만 하고 어디에도 기록하지 않습니다. 데이터베이스도 없어요. 다만 다른 사람이 화면을 캡처하는 것까지 막을 수는 없습니다.

업데이트는 어떻게 하나요?

설치할 때 쓴 명령을 한 번 더 붙여넣으면 최신 버전으로 바뀝니다.

삭제하고 싶어요.

Windows (PowerShell):

Remove-Item -Recurse -Force "$env:LOCALAPPDATA\tchat"

macOS / Linux:

sudo rm /usr/local/bin/tchat
안전한가요?

소스 코드가 모두 GitHub에 공개되어 있고, 설치 스크립트도 install.ps1 · install.sh에서 직접 열어볼 수 있습니다. 통신은 암호화(wss)되고, 다른 사람 화면을 망가뜨리는 특수문자는 서버에서 걸러집니다.
